Неофициальный online co-op мод для Cuphead 1.3.4. Форк [m1ttya/cuphead-online-coop](https://github.com/m1ttya/cuphead-online-coop)
на основе [nikrabaev/cuphead-online-coop](https://github.com/nikrabaev/cuphead-online-coop).
Исходная лицензия MIT и уведомления об авторстве сохранены. Файлы игры в сборку не входят.

**Обновить нужно обоих игроков.** Версия мода 0.1.7, сетевой протокол 7; предыдущие версии протокола несовместимы.

Исправления:

- Переработан опрос клиентского ввода для рывка и смены оружия; добавлены диагностические счётчики в F8.
- Исправлены реплики NPC, повреждённый текст, масштаб шрифтов, переносы и наложения в меню управления.
- Исправлены белые квадраты вместо значков оружия и экипировки.
- Исправлен пустой круг над Магменом: хост получает названия фактически назначенных клиентских кнопок.
  Уже открытые подсказки обновляются при смене привязок, включая длинные названия вроде ENTER.
- Добавлено восстановление фоновой музыки при подключении, загрузке сцены и после повтора босса.
- Установщики, ссылки в README и проверка обновлений теперь используют этот форк.

**Установка и обновление**

Закройте Cuphead на обоих компьютерах. Если BepInEx 5 уже установлен, скачайте `CupheadOnline.dll`
и замените `BepInEx/plugins/CupheadOnline.dll`. Затем запустите игру и проверьте версию 0.1.7 в F8.
Архив `CupheadOnline-v0.1.7.zip` содержит ту же DLL в структуре папок BepInEx, инструкцию и лицензию;
его можно распаковать в папку игры с уже установленным BepInEx 5.

Для полной установки на Windows можно использовать PowerShell:

```powershell
irm https://github.com/m1ttya/cuphead-online-coop/releases/latest/download/install-windows.ps1 | iex
```

На macOS предусмотрен установщик из оригинального проекта, перенастроенный на этот форк:

```bash
curl -fsSL https://github.com/m1ttya/cuphead-online-coop/releases/latest/download/install-macos.sh | bash
```

**Проверки и ограничения**

Release собран по DLL установленной игры; HookCheck подтвердил 17 целей Harmony и 22 отражаемых члена.
Пройдены 64 автоматические проверки. В двух запущенных копиях Windows проверены интерфейс и подсказки
удалённого игрока с настоящими картами Rewired: Z → K → ENTER. Проверки музыкальной части включали
три повтора Dragon и два восстановления принудительно остановленных BGM-источников клиента.

Дополнительно 9 ноября 2026 года пользователь подтвердил проверку в совместной игре на Windows:
физический геймпад клиента работает, музыка и звуковые эффекты слышны. По сообщению игроков,
пока всё работает как нужно и с багами они не столкнулись. Это результат их текущей игровой сессии.
На macOS эта версия по-прежнему не проверялась.
